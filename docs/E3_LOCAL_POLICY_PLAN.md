# E3 局部启停与验证长度实验方案

本方案在采集本轮训练标签和测试输出前固定，检验上一轮发现的局部重放空间能否由在线预测器兑现。目标是净 decode 耗时降低，不以预算变化次数为成功条件。

## 数据和预测器

`scripts/e3_policy_tasks.py` 固定 16 个训练提示、6 个独立校准提示、8 个新测试提示，文本互不重复；没有读取上一轮事后最优路径作为本轮训练标签。主题包括中英短答、翻译、结构化输出、代码、说明和思考。测试提示在拟合之前固定，标签不参与调参。

训练和校准数据在真实 serial 前缀的每一个位置收集：完整 DFlash2 草稿经 target 验证后，标注本步是否能输出超过 1/2/3 个 token。EOS 会减少实际输出，不能把 EOS 已接受后仍能获得额外 bonus 当成事实。标签与 serial oracle 的已提交 logits/输出比较，同时核对当前捕获特征。

前置模型输入为当前已提交 target 特征的 64 维固定随机投影、当前 anchor embedding 的 32 维投影、产生 anchor 的已知 target top-2 差距，以及上下文长度、已输出长度、思考开关、剩余输出上限四个标量。随机种子 80321，投影矩阵不训练；上下文和 anchor 特征按 RMS 归一化。模型不读取当前草稿或当前 target 验证结果。

后置模型额外读取当前草稿三个位置各自的 unary margin、选中候选距 unary 第一名的差距、实际 predecessor 下的 edge margin，共九个分数。分数不直接等同于接受概率。置信度附加路径必须与基础草稿给出相同 proposal；不改变草稿网络的数学算术或权重。

三个条件 logistic 头使用标准化并裁剪至 ±6 的输入；CPU FP64 LBFGS 最多 80 次迭代，L2 项为 `.005 * sum(weights**2)`。后续深度仅在前一个实际 progress 事件为真时拟合。随后在六个独立校准提示上拟合正斜率 Platt 校准，正则和迭代上限在代码中固定。三头条件概率相乘形成单调累计 progress 概率。模型在新测试计时前冻结并保存 SHA256，不在测试后再拟合或挑选参数。

## 策略与对照

七组为 serial、固定验证 1/2/3 个草稿、原始 DeepInfer 动态预算、仅草稿前启停 gate、完整两级 local。每任务每组七次，按七阶循环 Latin square 轮换，共 392 次计时。每次运行使用新状态和新的历史成本/接受率估计。

gate 先用前置模型和校准成本判断是否值得产生草稿；若启用则验证完整支持块。local 在前置启停后，用后置模型选择实际验证长度。前置成本只在启用草稿的档位加入草稿成本；后置决策时草稿已经生成，该成本必须加入所有候选，包括不验证草稿的档位，避免错误“退还”已发生的开销。输出长度上限是已知约束，可以限制最大档位；未来 EOS 不可见。

成本来自六个校准 prompt 的真实起始状态，每档三次；分别测原草稿、带置信度草稿、前置特征提取与验证/提交。策略按预测输出量除以估计动作成本选档。实际计时包含特征提取、CPU 预测、GPU 同步、置信度计算和所有控制开销；不能用模型估计代替实际完整耗时。

零草稿仍维护 target 特征，允许后续重新启用。纯 serial 不需要这些特征，保留其成本优势。固定组和原动态组调用未启用置信度的原草稿路径。原动态预算继续使用原始二进制、滞后经验率和同条件成本曲线，不代表完整 DeepInfer 引擎。

## 验证与解释

先独立比较六个非 serial 模式的完整输出、已提交 logits 和最终有效状态；正式计时只在计时外比较完整输出和最终有效状态。按 EOS 停止，若触及长度上限则记录并阻止将其称为完整答案。prompt 继续使用相同 decode 算术，原有 BF16 草稿对照差异和 target prefill 差异保持开放。

测量排除加载、prompt、首个已输出而待处理的 token、状态初始化、训练/校准、oracle 比对。报告每任务中位数、范围、整体中位耗时之和、有效 token/s、策略长度/启停分布，以及预测器耗时。最后在所有测试位置单独检查 Brier 分数；这发生在计时完成后且不再拟合，不将访问策略偏差下的部分标签当成完整预测评估。

若净收益不足或下降，保留结果，并区分启停误判、后置选择、预测开销和负载空间。七次重复与八种提示不足以支持广泛质量或显著性结论。代码输出不自动视为通过代码执行测试。本轮仅验证 greedy；使用当前草稿分数的新策略不因此获得随机采样正确性保证，多请求与长上下文仍未覆盖。

原始特征、投影训练行和日志留在私有实验目录；公开材料包含受控提示、输出、统计、固定输入投影种子和本轮拟合的小预测器参数，不发布 Qwen 权重或原始隐藏状态。
