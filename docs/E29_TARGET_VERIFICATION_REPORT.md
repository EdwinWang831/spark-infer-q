## Graph 具体移植了什么

上游TensorFold已经提供GPU分组专家以及按窗口大小、GDN奇偶状态和context缓存Graph的设计。本轮不是新增专家分组或新算术内核，而是为本工程DFlash target接入同样的执行边界，保留第5/15/25/35/45层的原有特征提取。stage与commit仍为原路径；请求私有state保持固定地址，按1～8行及两种GDN奇偶预热16张图。attention launch上界固定为已有2048容量；扩大launch上界的logits/特征/state一致性经过实测，没有假定成立。

独立诊断提示上14种宽度/奇偶/接受前缀组合全部通过，56对、112次verify计时；Graph预热6.239秒，正式decode内图捕获数没有增加。准备后的allocated快照为73.366 GiB，包含模型、对照、state、W8包和Graph等，不是Graph独占增量或峰值。冷启动、图缓存增长、4K+、多请求同时重放均未验证。

当前NVFP4 MoE已经按expert plan聚合同专家的行，不能再把“增加grouping”当新收益；32个前缀的逐层专家并集保留在证据中。它是选中权重footprint，不是真实DRAM流量；没有新的硬件带宽/SM利用率计数器，也没有声称重写了专家或投影重核。Graph减少发射工作，仍会执行相同的target数学运算。
