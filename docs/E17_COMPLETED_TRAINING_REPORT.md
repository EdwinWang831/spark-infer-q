# E17 补训：最终结果

E17 已于 2026-10-22 UTC 完成，终点 `PASS_E17_CHAIN`。普通 F1 线性预测器通过独立门槛和全部在线一致性检查，但没有显示相对 E16 的明确整体提速。没有替换默认执行器。

训练使用旧 E16 train 加新外部 train，共 45,081 个位置；另有 5,614 个 calibration 位置。四个固定候选先按 calibration 选定 `unweighted_f1` 并封存，然后才采集 90 条 test 提示、72 个 root、5,532 个位置。新提示为 OASST1 英文/中文人工问题及同组混合派生，不代表真实产品流量。

## 离线与在线

离线按冻结成本回放，相对固定预算 +13.1788%，分组 bootstrap 95% 区间 +11.6439%～+14.6941%；相对 E16 +0.2821%。这些是均匀串行前缀上的估算。

在线为预选 20 个 test root（英 8、中 8、mixed 4），六模式、三轮，共 360 次正式计时和 120 次独立模式一致性核对。耗时约 81.78 分钟。各模式输出、已提交 logits 和最终 live state 均一致。计时覆盖完整 decode 循环，排除 prompt、初始状态克隆和额外 oracle 检查。
