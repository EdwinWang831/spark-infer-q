# E25：补训预测器的实际 decode 对照

2026-10-23 UTC。在 E24 独立离线门槛通过后执行，不重新拟合、不改 target/DFlash/算子，也不重载权重。

比较三个已冻结方案：E24 扩展数据 MLP、E23 冻结 MLP、E17 已选线性预测器。两组 MLP 均使用已核对概率和决策的 float64 NumPy 后端，线性保留原运行时。三组共用 E24 封存的成本曲线和各自预先测得的 CPU 费用；实际计时包括所有实际预测开销。没有固定草稿对照，所以本轮只衡量预测器之间的差异。

从 E24 test 清单按固定 family/language 配额和加盐 SHA 选择 12 个独立 root（英8中4），选择器不读取离线性能/接受标签。覆盖中英文问答、Python、数学、真实角色多轮，以及采购表长输入。后者仍是同模板的受控覆盖，不能外推自然长文档。每条最大384个输出token，自然EOS停止，输入加输出及预留不超过2048。此批测试root已经用于E24评估，不应声称又产生了全新独立数据。

每条提示仅做一次相同的8-row prompt处理，然后克隆初始状态供各组使用。先生成串行参考，再对三组检查完整token、所有提交logits与最终live state，同时完成各组预热。参考token和真实角色prompt SHA均须与E24原采集记录一致。计时阶段每组重复3次，按任务交替正反顺序并循环轮转，使每个方案在每条提示上都占据一次首/中/末位置；每次另起独立状态和草稿缓存。计时结果的输出和最终状态在计时外核对。

主指标为各组总实际decode token（completion长度减prompt处理得到的首token）除以总decode墙钟时间，计入draft、特征、预测、调度、verify、commit及Python循环；模型初始化、prompt处理、克隆初态、正确性断言和结果落盘均在计时外。因此不将本指标表述为请求总延迟或含prefill的端到端速度。记录prompt处理时间作为范围说明。

汇总108次计时，按12个prompt root聚类、保留每个root内全部重复做4000次bootstrap，报告相对两组旧预测器的点估计和95%区间；同时检查各重复和语言/场景差异。区间跨零时保留不确定结论，不能把离线0.25%当作已证明的实际提速。12个root覆盖有限，即使区间为正也不代表一般用户负载。

任务为独立 `087-e25-online.json`，封存新模块、既有依赖、模型、E24评估和提示/参考元信息SHA；旧E17–E24运行源不覆盖，封存检查在开始/结束重复执行。任何错误停止并保留记录，不自动重试、部署或重启常驻worker。
