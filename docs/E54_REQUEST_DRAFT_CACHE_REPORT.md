# E54：保留每请求草稿投影，修复切换后的计算路径

2026-10-26。**严格门槛通过，作为显式研究选项保留，默认不变。** 本轮针对[E53](E53_LONG_CONCURRENCY_REPORT.md)中长请求A的144轮
预测概率、7轮验证宽度差异。目标是让请求交替执行时保留原增量计算语义，不重训
预测器、不修改target算术、权重、量化或冻结E29费用，也不重载常驻模型。

[事前方案](E54_REQUEST_DRAFT_CACHE_PLAN.md) · [用法](E54_REQUEST_DRAFT_CACHE_USAGE.md) · [可校验结果](../results/e54/2026-10-26-request-draft-cache.json)

## 已复现的机制

原drafter只有一份上下文投影/K/V缓存。切换请求会begin/reset，然后从整个
2040行后缀重建；单请求则移动缓存后只投影新提交的几行。两条投影路径对相同
特征的BF16结果并非总是逐位相同，进而改变草稿、置信特征和预算选择。

本轮在独立长请求A的第30/31/32/36个窗口，固定同一份已提交特征、绝对位置和
anchor，另外使用空投影缓存重建；诊断不送入target，不提交诊断草稿，每次核对
原请求的缓存和特征哈希、计数、位置均未改变。

| 窗口 | 概率最大绝对差（增量 vs 重建） | 草稿相同 | 重建概率复现E53组合路径 |
| --- | ---: | --- | --- |
| 30 | 0 | 是 | 完全一致 |
| 31 | 0.0096032711 | 否 | 完全一致 |
| 32 | 0.0161345047 | 否 | 完全一致 |
| 36 | 0.0070751078 | 是 | 完全一致 |

后三个窗口的context projection、K、V最大绝对差分别0.00390625、0.03125、
0.0625。四个窗口的绝对位置也与E53对应记录相同；不是换输入后得到的相似数字。
这是投影路径差异的直接复现，不是预测器重新拟合或target质量改变的证据。

## 实现与内存

新增显式`request_projection_cache=True`。每个`DraftState`持有上下文投影、
K/V三份张量及cached/appended/reused/window_start计数。调用期间临时绑定到
共享worker，返回或异常时恢复worker；不同owner/worker、嵌套绑定及释放后使用
均拒绝。引擎释放请求时先完成device fence，再释放投影缓存。

权重、padding、query Graph/workspace、screened head和target计算工作区共享。
每请求新增内存为**50MiB**（此checkpoint、max_context2048），与完整target历史
长度无关；默认关闭，原E53重建路径保留可复现。其他模型几何需要重新测量。

在E53资源估算上加此项，两路约82.13GiB、八路约**104.06GiB**，八路仍超过
当前88GiB分配限额约16.06GiB。没有分配或执行八路；这项修改解决语义隔离，
不宣称节省内存、增加Graph槽位、GPU合批或已支持1M。
