## 为何先做归因

E16线上只能观察已选宽度的真实耗时，其他宽度的成本未被实际执行，不能直接把模型错误和成本估计错误完整拆开。按原冻结曲线，线上8行验证的平均耗时偏差约为英文+4.45%、中文+5.24%（实际比预测更贵），绝对误差均值约4.01/4.27ms。低宽度的误差较小。三轮相关样本合并用于诊断，不是独立置信区间，更不是已证明的可回收加速。

因此下一步应在**训练位置**配对执行不同宽度，核验成本后再补训。不得用已经看过的E16测试/在线任务重新选择模型并称为独立新验证。

## 训练数据挖掘

仅E16原train的300提示/18,567位置进入权重和难例池。以冻结参考吞吐λ定义 `emitted/λ - cost_ms`，用所选动作与最佳可行动作的差得到等效毫秒损失。λ来自历史校准oracle，所有动作遵守已知剩余容量，已付草稿费计入。这里的“损失”基于近似成本，**不是测得的在线时间浪费**；有限特征无法预知全部oracle事件，也不能假定每个差距都能被训练消除。

训练位置中12,364个有非零等效损失；最高10%的位置占总等效损失34.42%。整体有11,325个选得比oracle长、1,039个选得短。但在语言/任务分散的高损失池里，方向相反，不能只把预算往小调：

| 难例复核池 | 结果 |
| --- | ---: |
| 位置 | 512 |
| 不同提示 /语义组 | 216 /60 |
| 英文 /中文 /混合 | 205 /205 /102 |
| 选得过长 /过短 | 171 /341 |
| 每提示上限 | 8 |
| 每语言内单任务族上限 | 约20% |

按训练集p90等效损失13.9752ms准备1..4倍权重，正式拟合时在每个条件深度有效样本内归一化。保留普通样本，不只训难例；加权与不加权都训练，不能预先认定加权有效。完整权重索引留在gitignored原始目录，公开难例索引只引用原合成train的位置。

## 已准备的正式对照

固定四候选：普通F0、损失加权F0、普通F1、损失加权F1。沿用七条件logistic、L2=.005、LBFGS80、CPU float64和独立未加权Platt；主体权重冻结。旧E16原train混合新train，旧test/OOD只回归；仅新calibration选择一次，再打开新test，计入全部预测/传输/特征费用。通过语言分层离线门槛后，另做新提示完整decode对照。

七深度补训针对完整block8后的验证预算；真正block4/不草稿的前置gate需要独立的、草稿前可得特征和配对标签，不能偷用本轮七草稿信号。E18已完成48个训练前缀的配对动作实测，见[E18结果](E18_PREDRAFT_COMPUTE_REPORT.md)；下一步将优先难例池的配对成本补齐，再进入正式标签采集与拟合。
