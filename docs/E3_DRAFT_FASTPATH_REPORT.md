# E3：草稿常量缓存与 greedy EOS 截断

**常量缓存单独没有建立稳定整体收益；缓存加 EOS 截断在本轮快约 1.26%。** 128 次计时和 24 次独立正确性运行通过。所有八个请求自然 EOS，完整输出与本轮 serial 及前一轮策略测试相同。见[公开 JSON](../results/e3/2026-10-20-draft-fastpath.json)和[固定方案](E3_DRAFT_FASTPATH_PLAN.md)。

## 改动与数学检查

缓存固定权重的 FP32 norm 副本，以及保持原 BF16 舍入边界的有界 RoPE sin/cos 表，共 914,432 bytes。没有缓存依赖上下文的 K/V，也没有改变草稿权重、attention、卷积、selector 或候选规则。原始和缓存实现共享同一批权重存储，没有重复加载模型。

GPU 预检覆盖位置 `[0,1,31,255,1023,1535]` 的 RoPE、全部 norm 的有/无 residual，结果逐 bit 相同。每个非 serial 正确性运行还逐步比较真实完整 draft hidden 和 proposal，均逐 bit 相同；target 已提交行 logits、完整输出和有效状态也相同。位置 1535 的点运算检查不等于验证了 1536 长上下文生成。

EOS 截断在草稿首次出现 EOS 时，仅保留它前面的 verifier 输入。若该 EOS 正确则输出停止；若错误则 correction 在此结束本步，因此 EOS 自身及其后续输入都无须验证。小词表上对最多 3 个草稿、所有 target-next 组合和输出上限共 12,300 例穷举，完整输出、提交行数、processed-draft 数和停止标记相同。完整 GPU 运行再次检验该契约，仅宣称 greedy 范围。

## 同轮完整 decode 对照

复用局部策略实验的八个提示作为实现回归，不能再称为新的未见测试。四组各四次，循环 Latin square 轮换，共 128 次。总计 394 个计时输出 token；首个 pending 输出、prompt、加载、状态初始化和 oracle 比对排除，草稿/验证/提交及控制开销包含。

缓存单独相对原始为 1.00213×，缓存加 EOS 为 1.01264×；EOS 版本相对仅缓存为 1.01049×。四次重复和计时波动不足以支持稳定或显著性结论。JSON 保存每任务范围及所有样本。

EOS 版本在全部计时中将 verifier 总行数从 2288 减至 2248，共 20 个步骤被裁剪。短加法/翻译分别比原始投机路径快约 18.0%/22.8%，但翻译仍慢于纯 serial，因为生成草稿的成本已经支付。不能把局部大幅减少解释成全局同等加速。

相同 prompt 初始状态上的 drafter 微计时每实现六次，AB/BA 各占三轮。八个 prompt 的中位耗时之和为原始 107.42 ms、缓存 102.93 ms，比值 1.04363×，平均各约 13.43/12.87 ms。这是草稿微计时，不是完整请求收益；整个 decode 主要仍由 target 和验证步数决定。

## 与局部预测器的关系

上一轮[两级策略](E3_LOCAL_POLICY_REPORT.md)在独立计时中相对其同轮 fixed3 快约 1.95%；本轮没有运行两级策略加缓存/EOS 的组合。两个比值不能相乘，两轮原始 baseline 也有计时差异。当前只能分别确认两项小幅观察，不能宣布已取得组合收益。

更大空间需要更有效的局部置信度与更广的合法验证范围。固定 checkpoint 配置 block_size=8，而当前探针只支持四行；上游说明其评测的四行限制来自当时 QSA 实现。八行 target 状态、GDN/QSA、SM121 算子与 drafter 官方语义仍需独立核对和实测，不因配置存在就宣称兼容或加速。

## 资源与复现

本轮 Torch allocated/reserved 峰值 72.4183/72.4492 GiB，结束前主机可用样本约 28.72 GiB；cgroup events 全零但不覆盖全部 CUDA 统一内存。最长有效提交位置为 278，分配容量 1536。结束后停止实验容器，OOMKilled=false，未部署服务。

本地 48 项标准库测试通过；运行源码摘要、前一轮输出、模型身份和旋转/norm 预检均核对。权重、私有原始日志和隐藏状态不入库。入口为 `scripts/e3_fast_probe.py --repetitions 4`，沿用外部环境；按公开 `harness_sha256` 部署并保存 `draft-fastpath-ready.json`，依赖同一实验目录的上一轮 `local-policy.json` 验证输出身份。导出为 `python3 -m scripts.e3_export_fastpath <private-json> <public-json>`。

原有官方 BF16 fidelity、target prefill、随机采样、长上下文、多请求和独立质量边界均未由本轮关闭。
