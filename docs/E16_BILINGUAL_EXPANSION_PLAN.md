# E16：中英文扩展训练与独立在线复核

执行前冻结。延续 E15 七条件 logistic 小头，不更改 Target / DFlash / Q4 主体权重。复用常驻 worker，禁止为换任务重载模型。本计划不预设训练后必然提速，不切换默认执行器。

## 数据与任务

`e16_tasks.py` 固定 **600 条人工编写的合成提示、120 个语义组**：英文240、中文240、中英混合120。每组两个英文、两个中文和一个混合任务，所有变体同split；按 family 内固定种子分组。训练300条/60组，校准100条/20组，新测试100条/20组，OOD100条/20组。语言比例在每个集合均为40/40/20。它们不是用户真实流量，也不能代表美国用户整体分布。

解释、实用指南、邮件写作、信息提取、规划、代码、排错、数学、上下文对话、长输入参与分组；工具调用格式和限制性编辑整族OOD，不用于训练、校准或选择模型。所有任务与E15训练/在线消融及E16最终在线提示独立。双语题仍有相关性，bootstrap以语义组为单位。

现有 Target 与草稿路径容量固定2048；长输入为1024/1536 token的不同编号运营记录，必要时保留首部和末尾截断，不声称是无损全文任务。输出cap128/384，部分中英文长输出cap1024，遇EOS提前停止。cap是安全上限，并非自然完成证据；实际EOS数、截断数和长度分布分别报告。4K需另做底层容量验证，本轮不实现。

## 标签与成本

每条提示走独立serial greedy轨迹，最多均匀抽取64个有后续token的位置，含首尾，不依据接受结果选点。最多38400个训练/校准/测试/OOD总样本，长轨迹不会挤占全部数据。报告属于抽样前缀replay，不能称为全位置吞吐。

每个选点以完整七草稿生成特征并与原缓存路径比较proposal token；标签沿用E15的累计进展、EOS/cap契约。remaining只用配置输出上限减已生成长度，不能使用未来EOS。校准提示首位置逐宽度1..8预热及各三次计时，验证committed logits和live state；短/长context中位成本曲线仅用校准集。F0保守计入F1特征增量，线上全路径实测决定结论。

## 模型、消融与门槛

沿用F0=25维、F1=137维、投影seed20261021、L2=.005、CPU float64 LBFGS80和独立Platt校准。仅按校准policy tokens/ms选择，之后计算test/OOD，不按测试换模型。七深度支持量、累计Brier、英文/中文/混合分层指标与语义组bootstrap都保留。选定模型需要满足E15离线门槛（捕获≥30%、收益/捕获区间下限>0、动作差异等），额外要求英文和中文各自测试收益区间下限>0，才进行最终在线复核。失败则记录负结果，不继续调同一个test。

先对E15已冻结F0/F1做独立12任务在线消融（英文5/中文5/混合2），fixed/native_cached/F0/F1四组，每组3轮。它不参与新数据拟合，也不决定E16测试上的模型选择。

最终在线提示另冻结于`e16_online_tasks.py`：**20条新任务，英文8、中文8、混合4**，包含自然结束、1024/1536输入、cap1024的长输出；五组（校准固定宽度、原生lagged预算、E15 F1、E16 F0、E16 F1），每组3轮，共300次正式计时和100次独立serial oracle对照。对新旧头采用同一E16成本曲线，隔离训练效果；F0/F1全部报告，但被选定的一组已由校准冻结，禁止线上事后挑赢家。计入草稿、cache建立/追加、特征/CPU传输/推理及预算开销，排除prompt、clone和oracle。固定组是post-draft对照；若校准fixed1胜出，需另补target-only，不能将支付草稿的fixed1视为真实执行基线。

最终按语言、自然EOS/cap、长短输入/输出分别报告，保留退化任务和所有重复轮次。总体收益不是跨硬件TensorFold排名，也不证明随机采样或GPU多请求batch。

## 执行与证据

新增实验文件，E15实跑代码不修改。600任务预先tokenizer检查容量，然后独立smoke；12片各50条，片内逐提示落盘、片尾SHA封存。有限任务链`e16_pipeline.py`只投递一个任务并等待完成，不加载权重、不自动重试、不重启worker。任一任务失败停止后续链；完整采集才训练，门槛通过才在线。所有源码与数据SHA、同PID/load_count、模型JSON、原始计时和分语言结果留档。原始特征在gitignored目录，公开报告去除私有路径。
